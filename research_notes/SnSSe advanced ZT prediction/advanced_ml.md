# Advanced Sn–S–Se ZT screening

The runnable workflow is `sn-s-se-advanced/src/run_advanced.py`. It reads the curated ESTM dataset and the extracted Starrydata curves under the supplied `Datasets` directory. The resulting training table contains 5,255 rows and 880 composition groups: 4,830 ESTM rows plus 425 rows from Sn–S–Se and Co₃InSnSSe Starrydata curves. The source table is preserved in `sn-s-se-advanced/outputs/tables/training_tidy.csv`; the extracted long Starrydata subset is in `starry_snsse_long.csv`.

Composition strings are parsed into elemental fractions and compact descriptors: element fractions, number of elements, mixing entropy, weighted/min/max/range/std statistics for atomic mass, atomic number, electronegativity and radius, formula mass, Sn–Se imbalance, S/Se ratio, and temperature. This is a transparent lightweight analogue of the reference paper's Matminer feature generation; it does not pretend to reproduce Matminer values when that package is unavailable.

The target is measured ZT. The script evaluates Ridge with in-fold SelectKBest, Random Forest, ExtraTrees and Gradient Boosting. The primary validation is GroupKFold by composition, with a separate held-out composition-group split. ExtraTrees is strongest: grouped-CV R² 0.698, MAE 0.109, RMSE 0.193; held-out-group R² 0.745, MAE 0.097, RMSE 0.166. Permutation importance is temperature 0.891, Te fraction 0.112, Sb fraction 0.054, Ge fraction 0.054 and Ag fraction 0.053.

The candidate screen generates Sn–S–Se base compositions with Ag, Na, Cu, Sb, Te, Zn, Fe, Co or Ga substitutions of 0–10%, Se fractions from 0 to 1, and temperatures 300–600 K. Every candidate row is marked `extrapolation_flag=True`. No newly generated doped candidate reaches predicted ZT ≥ 1; the maximum is approximately 0.819. This is a model/data result, not evidence that the materials cannot reach ZT ≥ 1. The measured source contains reference compositions SnS0.88Se0.12, SnS0.91Se0.09, SnS0.94Se0.06 and SnS0.97Se0.03 with observed maxima above 1, showing that the threshold is present in known data but that the present feature-only model cannot justify a new ≥1 claim. DFT, phonon stability, synthesis feasibility and experimental validation remain required.

Plots include held-out-group and grouped-CV parity graphs for all models, permutation feature importance, measured Sn–S–Se curves, and a candidate ZT heatmap. The report should distinguish these measured references from model-generated candidate predictions and should not report the candidate screen as experimental discovery.
